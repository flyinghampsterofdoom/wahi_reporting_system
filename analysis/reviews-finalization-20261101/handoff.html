Completed workflow

  • Every morning: claim one Pacific-calendar occurrence at 10:00 AM, synchronize new/updated reviews, queue the changed-source cohort, analyze in bounded batches, publish intelligence and refresh the dashboard. PDT/PST conversion uses the existing timezone utilities; hourly synchronization is removed.
  • Sync & Analyze Now: prominent Admin action starts the same durable pipeline immediately. Manual and scheduled work join an active synchronization. Stable IDs, source versions, unique jobs and cached results prevent duplicates and repeated analysis of unchanged reviews.
  • Analyze Historical Reviews: separate cost-preview dialog defaults to reviews without a successful assessment. Batches of ten can pause and resume safely. Explicit full reanalysis creates a new configuration/version and retains previous findings. Selecting another model does not automatically reprocess old history.
  • Independent recovery: a successful Google sync stays complete when AI fails. Pending and failed analysis remains visible with retry controls. Bounded transient retries persist their next attempt time. Unknown paid outcomes retain reservations and require explicit recovery. Superseded source versions are skipped.
  • Visible status: last successful sync and analysis, new/updated counts, analyzed/awaiting/failure counts, progress and history. Release changes refresh the dashboard without full-page reloads. Idle status checks poll the backend only, with no Google activity, and pause while the document is hidden.
  • OpenAI controls: encrypted key entry/removal, selected model, connection test, synthetic compatibility verification, enable/disable processing, independent automatic-analysis toggle, dated prices, monthly/request budgets, cost reservations, history and clear errors.
  • Data integrity: source text and business responses remain separate from versioned AI records. Existing interpretations remain visible during model changes. Metric version 2 counts an explicit insufficient-information assessment as processed, while contributing no invented sentiment or topic.
